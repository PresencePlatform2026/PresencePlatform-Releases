How do I tell them apart?
  • Presence — the smaller classic ESP32 board, micro-USB or USB-C, no metal network jack.
  • Presence Pro — ESP32-S3 with a metal RJ45 Ethernet jack on the board, and a microSD slot. This is the Waveshare ESP32-S3-ETH.
  • Presence Pro WiFi — ESP32-S3 with no RJ45 jack, typically two USB-C ports side by side.

Both ESP32-S3 products currently install the same firmware image, which detects the Ethernet chip at startup and configures itself accordingly — so if you pick the wrong one of those two, the device still works correctly. Only the classic ESP32 is a genuinely different build.

2. Install

Choose a product above to continue.
  1. Use Chrome or Edge on a computer (Web Serial doesn't work on phones/iPads).
  2. Connect the board's USB port to this computer with a data cable.
  3. Click Connect below and pick the board's serial port (shows as "Silicon Labs CP210x" or "USB Serial Device").
  4. Choose Install. For a brand-new board, pick "Erase device" when offered. Takes ~3 minutes.
  5. When it reboots, join the PresenceSetup_xxxx WiFi network it broadcasts and follow the setup portal.
  6. After setup, the dashboard lives at presence.local (presence-platform.local:8090 on v3.0.1).

Board not showing up? Hold the BOOT button while plugging in USB, then try Connect again. Still nothing — swap the cable; charge-only cables are the #1 cause.

Already-configured device? Choosing "Erase device" wipes its WiFi credentials, admin password, and tracked devices — you'll re-onboard from scratch. Existing devices normally update via Settings → Check for Updates instead of this page.
What gets installed

Bootloader, partition table, OTA data, application, and web dashboard — the same signed artifacts published in the GitHub releases. Future updates are delivered over the air with RSA-2048 signature verification.
